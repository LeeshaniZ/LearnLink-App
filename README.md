# LearnLink

LearnLink is a student-focused learning and collaboration application. Its screens cover common study workflows such as sharing posts, joining study groups, accessing learning resources, chatting, and tracking tasks.

## Application areas

- Sign-up and login screens
- Home and navigation
- Study groups and shared posts
- Chat interface
- Learning resources
- Tasks and task details
- Motivation screen

## Technology

- Flutter
- Dart

## Getting started

1. Install the Flutter SDK and confirm that it is available on your PATH.
2. Clone this repository.
3. Run `flutter pub get` in the Flutter project directory (once the project has a `pubspec.yaml`).
4. Launch the application on an emulator or connected device with `flutter run`.

## Repository note

The current repository contains screen source files. Add the Flutter project configuration (including `pubspec.yaml`) and any required assets before expecting a fresh clone to run independently.
